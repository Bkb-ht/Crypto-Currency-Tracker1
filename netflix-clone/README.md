# Netflix Clone (Frontend)

A Netflix-like UI built with **React + Vite + Tailwind** using **mock data** and **LocalStorage**.

## Features
- Mock login
- Browse page with Hero + horizontal rows
- Search page
- My List (watchlist) persisted in LocalStorage
- Details modal + Watch page placeholder

## Run
```bash
npm install
npm run dev
```

## Notes
- Replace `src/data/mockMovies.js` with TMDB API later if you want real movies.

## 🚀 Quick Start Guide

1. **Start the system:**
   ```bash
   cd library-management
   start.bat  # Windows
   # or
   ./start.sh  # Linux/Mac
   ```

2. **Open browser:** http://localhost:3000

3. **Register using any example above**

4. **Login with your credentials**

5. **Add sample books from the list**

6. **Test borrowing and returning books**

## 📱 What You'll See After Registration

1. **Automatic Login** - You'll be logged in immediately
2. **Dashboard** - Shows library statistics
3. **Navigation Menu** - Access to all features:
   - 📊 Dashboard
   - 📚 Books Management
   - 👥 Members Management
   - 🔄 Transactions
4. **Your Membership ID** - Automatically generated (e.g., LIB1703123456789)

## 🆘 Troubleshooting

**If registration fails:**
- Check if MongoDB is running
- Verify backend server is on port 3001
- Check browser console for errors

**If you can't access the site:**
- Make sure frontend is running on port 3000
- Check if ports 3000 and 3001 are available
- Try refreshing the browser
